# STM32H743VIT6 + SSD1306 0.96" — Осциллограф + FFT

## Подключение

```
STM32H743VIT6          SSD1306 OLED 0.96"
─────────────          ──────────────────
3.3V          ──────── VCC
GND           ──────── GND
PB8  (I2C1 SCL) ─[4.7к]─ SCL
PB9  (I2C1 SDA) ─[4.7к]─ SDA

PA3  (ADC1_IN15) ────── Вход сигнала (0..3.3В)
GND              ────── GND сигнала
```

> **Важно:** подтяжка 4.7 кОм на 3.3В обязательна для I2C.
> Если на модуле OLED уже есть резисторы — проверь номинал (обычно 10к, замени на 4.7к для 400 кГц).

## Адрес I2C

Дисплей 0x3C (SA0=GND) → в коде `SSD1306_I2C_ADDR = 0x78` (7-бит << 1).
Если SA0=VCC → адрес 0x3D, замени на `0x7A`.

## Разметка экрана 128×64

```
┌────────────────────────────────┐  Y=0
│ ~~~~  осциллограмма  ~~~~      │  30px
├────────────────────────────────┤  Y=30
│ ▁▂▄█▆▃  спектр FFT  ▂▃▁       │  25px

│ 1.0kHz  THD 2%                 │  8px
└────────────────────────────────┘  Y=63
```

## Параметры

| Параметр          | Значение                      |
|-------------------|-------------------------------|
| MCU               | STM32H743VIT6 @ 480 МГц       |
| ADC               | ADC1, 16-bit, оверсэмплинг 4x |
| Вход              | PA3 (ADC1_CH15), 0..3.3В      |
| Частота дискрет.  | 20 кГц (TIM6 TRGO)            |
| Размер FFT        | 256 точек                     |
| Разрешение FFT    | 78.1 Гц/бин                   |
| Диапазон FFT      | 0..10 кГц                     |
| Окно              | Ханна                         |
| I2C               | I2C1 @ 400 кГц                |
| FPS (дисплей)     | ~10–12 кадр/с                 |
| FFT время         | ~0.15 мс @ 480 МГц (CMSIS-DSP)|

## Сборка (STM32CubeIDE)

1. Создай проект STM32CubeIDE → STM32H743VIT6
2. В `.ioc` включи:
   - I2C1 (PB8/PB9), Fast Mode 400 кГц
   - ADC1 CH15 (PA3), 16-bit, External Trigger TIM6
   - TIM6, период = `(240_000_000 / 20000) - 1 = 11999`
   - DMA1 Stream 0 для ADC1
   - CMSIS-DSP: добавь `arm_cortexM7lfdp_math.lib`
3. Скопируй файлы из папок `Core/` и `Drivers/SSD1306/`
4. В линкер-скрипте проверь наличие секции `.axi_sram`

## Добавить секцию AXI SRAM в линкер-скрипт

В `STM32H743VITX_FLASH.ld` найди MEMORY и добавь (если нет):

```ld
MEMORY
{
  FLASH    (rx)  : ORIGIN = 0x08000000, LENGTH = 2048K
  DTCMRAM  (xrw) : ORIGIN = 0x20000000, LENGTH = 128K
  RAM_D1   (xrw) : ORIGIN = 0x24000000, LENGTH = 512K   /* AXI SRAM */
  RAM_D2   (xrw) : ORIGIN = 0x30000000, LENGTH = 288K
  RAM_D3   (xrw) : ORIGIN = 0x38000000, LENGTH = 64K
  ITCMRAM  (xrw) : ORIGIN = 0x00000000, LENGTH = 64K
}
```

В SECTIONS добавь:

```ld
.axi_sram (NOLOAD) :
{
  *(.axi_sram)
  *(.axi_sram*)
} >RAM_D1
```

## HSE

Код настроен на **HSE = 25 МГц** (типично для минималок на H743VIT6).
Если на плате 8 МГц — измени `PLLM=2, PLLN=192, PLLP=2` для тех же 480 МГц:
- Vco = 8/2 × 192 = 768 МГц → нет, вне диапазона.
- Для 8 МГц HSE: `PLLM=2, PLLN=120, PLLP=1` → 480 МГц.

## Расширение

- **Тригер по фронту** — добавь поиск перехода через ноль в `adc_buf[]` перед отрисовкой
- **Кнопки** — масштаб времени / частотный диапазон
- **UART** — стриминг `adc_buf[]` в ПК для записи
- **Авто-усиление** — если амплитуда < 10% экрана, увеличить масштаб
